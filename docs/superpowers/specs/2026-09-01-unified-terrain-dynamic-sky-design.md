# 统一连续地形与动态天空重建设计

日期：2026-09-01
状态：用户已确认设计方向，待书面规格复核

## 1. 改造目标

重建现有中央三维场景，使其在保持浏览器实时旋转、缩放和五阶段切换的前提下，更接近最初五联航拍效果图。重点解决以下问题：

- 地面与基坑由独立网格拼接造成的可见裂缝。
- 堆体表面过于平滑或低多边形化，缺少真实工程边坡细节。
- 静态天空图片不会随相机和时间产生空间变化。
- 几何树木和规则排列造成的“玩具模型”观感。

现有UI布局、两个场地、报告数据、缺失值规则和操作方式保持不变。

## 2. 已确认方案

采用“统一连续地形 + 动态天空”方案，不再继续修补“地面开洞 + 独立坑壁 + 独立堆体”的叠放结构。

整个场地使用一张连续的高密度三角地形网格。地面、坑口、坑壁、坑底和阶段堆体共享同一套顶点与索引。阶段切换时更新这些顶点的高度状态和地表材质区域，从结构上消除连接裂缝。

天空进入Three.js三维场景，使用天空穹顶和缓慢移动的程序化云层；删除中央面板的静态天空CSS背景。

## 3. 统一地形架构

### 3.1 网格范围

- 地形覆盖中央可视区域及相机允许旋转后能够看到的外围区域。
- 默认使用约160×120个分段，形成约1.9万个顶点；根据浏览器实测性能可在140×100至180×140之间调整。
- 使用索引三角网并计算平滑法线，避免明显三角面和折线阴影。
- 地形边缘延伸到雾区之外，正常旋转和缩放范围内不得看到悬空平面边缘。

### 3.2 连续区域函数

每个顶点由同一套场地距离函数判断其位置：外围地面、坑口过渡、边坡、坑底、堆体平台或堆体坡面。坑口边界使用平滑的不规则闭合曲线，并通过连续插值形成边坡，不生成独立开口。

地形高度函数必须满足：

- 坑口内外高度连续。
- 坑底至边坡连续。
- 台阶平台与坡面之间可以有工程折坡，但不得出现未连接的空洞。
- 同一阶段任意相邻顶点的网格索引保持完整。

### 3.3 五套高度状态

| 阶段 | 地形高度与主要形态 |
| --- | --- |
| 原始基坑 | 外围缓坡、环场道路、岩石边坡、低洼不规则坑底 |
| 基坑整理与防渗 | 与基坑共用几何高度，坡面更规整，坑底略平整 |
| 磷石膏堆填 | 坑内形成不规则白色台阶堆体，保留宽平台和连续运输坡道 |
| 封场覆土 | 在堆体高度基础上增加薄覆土层，平台边缘稍柔化并保留施工车辙 |
| 植物修复 | 与覆土总体高度一致，通过植被、裸土斑块和排水路线表现恢复状态 |

高度状态在初始化时预计算并缓存。切换阶段时更新同一地形网格的顶点高度，不创建新的WebGL画布。

## 4. 地表材质

### 4.1 材质分区

使用连续地形的区域权重决定材质：

- 外围：岩土、碎石和少量草地混合。
- 原始基坑：裸岩、风化土和坑底压实土。
- 防渗阶段：坑内使用黑色HDPE膜，坑外仍为岩土。
- 堆填阶段：坑内主体为白灰色磷石膏，道路为灰白压实材料。
- 覆土阶段：主体为棕色覆土，车辙使用较深的土色。
- 修复阶段：草地、裸土和灌木区按噪声权重不规则混合。

材质边界使用窄范围平滑混合，不出现一圈纯色硬边。

### 4.2 纹理映射

- 复用现有本地岩土、膜面、磷石膏、覆土和植被纹理。
- 地形坡面采用三向投影或等效的坡度修正映射，避免陡坡纹理被纵向拉长。
- 同一颜色纹理可作为细小凹凸信息，但凹凸强度必须受控，避免砂纸感。
- 纹理加载失败时回退到现有程序化基础材质。

## 5. 工程细节

### 5.1 道路和排水

- 环场施工道路沿不规则坑口外侧布置，并贴合统一地形高度。
- 堆填运输道路由地形高度函数生成连续路线，跨平台处形成自然坡道，不悬空、不穿入堆体。
- 排水出口固定在参考图前侧低点，连接碎石排水沟和短管。
- 防渗膜拼接缝贴合坑底和坡面，不使用固定平面高度。

### 5.2 植被

- 远景林地使用带透明通道的树木贴片或低面数交叉面实例，避免几何圆球和整齐树列。
- 修复阶段使用实例化草簇、灌木和幼树，位置由确定性噪声控制。
- 植被密度不均匀，保留裸土、排水线路和维护道路。
- 植物根部高度从当前地形函数读取，避免悬空或埋入坡面。

## 6. 动态天空和光照

### 6.1 天空穹顶

- 使用包围场景的大型天空穹顶，不再依赖CSS背景图片。
- 天空颜色包含从地平线灰蓝到高空浅蓝的渐变。
- 使用程序化多层噪声生成柔和积云和阴影区域。
- 云层仅缓慢漂移，不做天气系统、降雨或昼夜循环。

### 6.2 光照联动

- 使用方向光模拟云层后的太阳光，阴影保持柔和。
- 使用半球光补充天空和地面反射色。
- 相机旋转时天空穹顶保持无限远效果，云层方向产生空间一致性。
- 场景雾颜色与地平线颜色一致，使远景树林自然融入天空。

## 7. 相机与交互

- 保留鼠标左键拖动旋转和滚轮缩放。
- 保留禁用平移和漫游。
- 调整相机近远裁剪面和缩放范围，任何允许视角下都看不到地形边缘或天空穹顶边界。
- 默认视角接近参考图的斜俯视航拍角度。
- 阶段切换时允许短暂高度插值，持续时间控制在约0.6秒；用户连续点击时直接从当前状态过渡到新状态。

## 8. 文件职责

计划将场景拆分为以下模块：

```text
src/scene/
├─ createScene.js               相机、渲染循环、灯光与控制器
├─ createSiteModel.js           场景对象装配和阶段切换接口
├─ createUnifiedTerrain.js      连续地形网格、顶点状态和材质区域
├─ terrainProfiles.js           场地边界、距离函数和五阶段高度函数
├─ createDynamicSky.js          天空穹顶、移动云层和时间更新
├─ createEngineeringDetails.js  道路、膜缝、管道、排水沟
├─ createVegetation.js          草簇、灌木、幼树和远景林带
└─ createTexture.js             本地纹理和失败回退
```

`createSiteModel(renderer)`继续返回`{ root, applyStage, update, dispose }`。`createScene`在每一帧调用`update(deltaTime)`，用于阶段高度插值和云层漂移。

## 9. 性能边界

- 桌面浏览器1920×1080为主要目标。
- 目标为普通独立显卡或近年集成显卡上稳定交互，优先保持30 FPS以上。
- 地形只使用一张主要高密度网格。
- 草木、碎石等重复对象使用实例化绘制。
- 动态云层使用一个天空材质，不使用粒子云或体积光追踪。
- 渲染倍率继续限制在1.75以内。

## 10. 数据和UI边界

- 不改变三板湖和东西泉的任何报告数据。
- 不改变五阶段名称、顺序和缺失值显示。
- 不改变页面三栏布局、标题、字体和按钮结构。
- 两个场地继续共用一套示意模型。
- 继续显示“示意模型，非真实地形复原”。

## 11. 验证标准

### 11.1 几何

- 地面、坑口、坑壁和坑底属于同一个索引网格。
- 自动测试确认地形网格没有边界开口或未引用的内部顶点。
- 在允许的最小、最大缩放和四个主要旋转方向下，坑口不得出现背景色裂缝。

### 11.2 五阶段视觉

- 原始基坑具有自然岩石坡面和不规则坑底。
- 防渗膜完整覆盖坑底与坡面，膜缝和排水管清楚可见。
- 磷石膏堆体具有宽台阶、连续运输坡道和压实痕迹。
- 覆土阶段无大面积磷石膏穿透，车辙贴合地形。
- 修复阶段植被分布不规则，树木不呈整齐圆球排列。

### 11.3 天空和环境

- 删除CSS静态天空图片引用。
- 相机旋转时天空保持三维包围效果。
- 连续观察10秒可看到轻微云层漂移。
- 天空、雾、远景林带和地形没有明显图层断裂。

### 11.4 回归

- 两个场地各五阶段均可进入。
- 场地切换保持当前阶段。
- 页面始终只有一个三维画布。
- 旋转、缩放、窗口调整和资源释放正常。
- 自动测试、生产构建和浏览器控制台检查全部通过。
