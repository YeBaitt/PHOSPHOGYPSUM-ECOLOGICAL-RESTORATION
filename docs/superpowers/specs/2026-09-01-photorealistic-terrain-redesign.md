# 磷石膏堆场写实三维场景改造设计

日期：2026-09-01  
状态：用户已确认

## 目标

保留现有双场地、五阶段、报告数据和操作方式，只重建中央三维场景，使其在浏览器中接近已确认参考图的自然航拍效果，而不是规则圆台式示意模型。

## 已确认范围

- 两个场地继续共用一套示意模型，不还原真实地形或真实尺寸。
- 基坑使用不规则多边形边界、起伏岩土坡面和低洼坑底。
- 防渗阶段显示黑色膜面、拼接缝、褶皱感和排水管。
- 堆填阶段显示白灰色磷石膏、不规则分层边坡、平台和运输道路。
- 覆土阶段显示棕色压实覆土和施工车辙。
- 修复阶段显示不均匀草地、灌木和幼树，保留部分裸土斑块。
- 场地外围显示施工便道、排水沟、碎石和远处林带。
- 使用项目内本地材质；运行时不依赖网络。
- 继续支持鼠标拖动旋转和滚轮缩放，不增加漫游、车辆动画或后台功能。

## 验收标准

1. 基坑和堆体轮廓肉眼可见地不规则，不再呈规则圆柱或同心圆台。
2. 五个阶段仍按原顺序切换，且工程特征清楚可辨。
3. 页面原有文字、场地切换和报告数值不改变。
4. 1920×1080 下中央场景保持流畅，控制台无错误。
5. 本地纹理加载失败时仍能以可辨认的基础材质显示。
