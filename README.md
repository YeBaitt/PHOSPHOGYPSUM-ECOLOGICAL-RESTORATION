# 磷石膏堆场生态修复可视化平台

这是一个在电脑浏览器中运行的三维可视化页面，用于辅助展示磷石膏堆场从基坑到植物修复的变化过程。

页面目前包含：

- 三板湖磷石膏库、东西泉磷石膏库两个场地，可在页面顶部切换；
- 原始基坑、基坑整理与防渗、磷石膏堆填、封场覆土、植物修复五个阶段；
- 可拖动旋转中央三维模型，并通过鼠标滚轮缩放；
- 四周展示报告中能够确认的数据，缺失的数据会显示“暂无数据”。

> 说明：中央模型用于辅助理解修复过程，不是对两个场地真实地形的精确还原。

## 一、运行前的准备

项目使用 Node.js 运行。Node.js 可以理解为前端项目在本地电脑上的运行环境。

如果电脑还没有安装 Node.js，请先安装较新的 Node.js 长期支持版（LTS）。安装后打开 PowerShell，分别运行：

```powershell
node -v
npm -v
```

如果两条命令都能显示版本号，说明安装成功。

## 二、第一次启动项目

打开 PowerShell，进入项目目录：

```powershell
cd D:\WorkRoot\DuiKuang
```

安装项目所需的软件包：

```powershell
npm install
```

这一步通常只需要在第一次运行项目，或项目依赖发生变化时执行。

安装完成后，启动开发服务器：

```powershell
npm run dev
```

“开发服务器”是让本地网页能够在浏览器中访问的小程序，并不代表页面已经发布到互联网。

终端中出现类似下面的内容后，说明启动成功：

```text
Local: http://localhost:5173/
```

## 三、在浏览器中预览

打开 Chrome、Edge 或其他现代浏览器，在地址栏输入：

```text
http://127.0.0.1:5173/
```

也可以按住 `Ctrl` 键并点击 PowerShell 中显示的 `Local` 地址。

如果端口 `5173` 已被其他程序占用，项目可能会自动使用 `5174`、`5175` 等端口。此时应以 PowerShell 中实际显示的 `Local` 地址为准。

进入页面后，可以：

1. 点击顶部场地名称，在三板湖和东西泉之间切换；
2. 点击底部五个阶段按钮，查看修复过程的变化；
3. 按住鼠标左键拖动，旋转中央模型；
4. 滚动鼠标滚轮，放大或缩小模型。

页面优先按照 16:9 的电脑全屏画面设计。按浏览器的 `F11` 键可以进入或退出全屏。

## 四、停止运行

回到正在运行项目的 PowerShell 窗口，按：

```text
Ctrl + C
```

如果终端询问是否终止任务，输入 `Y` 后按回车即可。

## 五、以后再次启动

依赖没有变化时，不需要重复运行 `npm install`。只需执行：

```powershell
cd D:\WorkRoot\DuiKuang
npm run dev
```

然后在浏览器中打开终端显示的地址。

## 六、检查正式构建效果

如果想确认项目能否生成用于发布的文件，可运行：

```powershell
npm run build
```

构建成功后，生成的文件位于 `dist` 文件夹。可以继续运行：

```powershell
npm run preview
```

再打开 PowerShell 中显示的地址进行预览。该地址通常是 `http://localhost:4173/`，但仍以终端实际显示为准。

## 七、运行项目检查

项目包含自动检查，可使用下面的命令运行：

```powershell
npm test
```

看到所有测试通过（passed）即可。

## 八、常见问题

### 1. 提示“无法识别 node、npm”

通常是 Node.js 没有安装成功。请重新安装 Node.js LTS，安装完成后关闭并重新打开 PowerShell。

### 2. 浏览器提示“无法访问此网站”

请确认运行 `npm run dev` 的 PowerShell 窗口没有被关闭，并使用终端里实际显示的 `Local` 地址。

### 3. 页面打开后是空白或三维模型不显示

先刷新页面；如果仍未恢复，请使用较新版本的 Chrome 或 Edge，并确认浏览器已启用硬件加速。三维模型需要浏览器的 WebGL 图形功能。

### 4. 修改代码后没有看到变化

一般保存文件后页面会自动更新。如果没有更新，可以按 `Ctrl + F5` 强制刷新浏览器页面。
